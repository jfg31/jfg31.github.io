# Overview — portfolio-site

## Propósito

Portfolio profesional bilingüe (EN/ES) de Jose Flores: ingeniero de automatización e IA que también construye productos.

## Problema que resuelve

Reunir en un solo lugar público todo el trabajo hecho (software, automatización, IA, homelab, hardware) para empleadores y clientes, y servir de base para el resume, LinkedIn y el perfil de GitHub.

## Qué hace (resumen funcional)

- Export filtrado desde el cerebro (solo casos públicos)
- Linter de privacidad que bloquea datos sensibles
- Sitio Astro con temas intercambiables y toggle EN/ES
- Deploy a GitHub Pages
